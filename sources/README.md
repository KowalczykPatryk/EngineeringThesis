# Sources description

This project builds upon the [original project repository](https://github.com/mmajewsk/gym-lartpc2d) created by my engineering thesis supervisor. The [fork](https://github.com/RL4Phy-AGH/gym-lartpc2d/) of the original repository also contains initial [ROOT dataset](https://www.deeplearnphysics.org/DataChallenge/#data) analysis and early development code.

Updated dataset which is currently used is based on the initial one. [Simulation software](https://github.com/RL4Phy-AGH/lartpc_sim) that produces it was reverse engineered by my thesis supervisor.

3D plots:
- [geeksforgeeks - integrating PyVista with PySide6](https://www.geeksforgeeks.org/python/pyvista-and-qt-integration/)
- [PyVistaQt docs - it connects PyVista with any Qt binding](https://qt.pyvista.org/index.html)
- [PyVista docs about plotting](https://docs.pyvista.org/api/plotting)

GUI:
- [PySide6 widgets docs](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/)
