## GUI
For the GUI I use PySide6 as it is the official Python binding for Qt6.

## 2D plots
I use pyqtgraph for 2D plots.

## 3D plots
For 3D plots I use PyVistaQt which is a wrapper around PyVista that allows embedding PyVista plots into Qt applications. It uses QtPy which is a compatibility layer that lets Python programs work with different Qt bindings.
